1- Crea una clase que llamaremos Bus. Sus atributos serán: capacidad, pasajeros, conductor

2- Sus metodos: subir, bajar, conductor

3- El objeto conductor es de una clase (Conductor) cuyos atributos son: nombre, licencia

4- Al crear el objeto se asigna también el conductor. No pueden subir más pasajeros que los máximos admitidos y no pueden bajar más de los que no hay
