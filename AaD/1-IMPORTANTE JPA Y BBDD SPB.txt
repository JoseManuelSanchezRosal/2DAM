1- CAMBIAR A "CREATE"  EL DDL-AUTO CUANDO SE QUIERA CREAR LA BBDD AL ARRRANCAR LA APP
  jpa:
    open-in-view: false
    hibernate:
      ddl-auto: update         # crea/actualiza tablas en desarrollo # CREATE PARA CADA VEZ QUE ARRANCA LA APLICACION CREA LA BASE DE DATOS DE NUEVO
    properties:
      hibernate:
        format_sql: true
        jdbc.lob.non_contextual_creation: true
